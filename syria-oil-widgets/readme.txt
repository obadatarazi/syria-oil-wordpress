Portable Elementor widgets for the Syria Oil portal.

== Description ==

Elementor widgets under the "Syria Oil" category (see theme for full list).

Oil & Gas Prices (EIA API key + refresh) are configured in the Syria Oil theme
options panel when that theme is active. The plugin still owns cron + cache.

Site-wide widget defaults can be set via the theme filter `syria_oil_widget_default`.
